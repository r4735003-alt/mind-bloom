# MindBloom Production Web App — Backend Upgrade Starter

This package upgrades the MindBloom browser MVP toward a real deployable web product.

## Included
- Child-friendly responsive UI from the previous MVP
- Age bands: 2–4, 4–6, 6–9, 9–12, 12–15, 15–18, 18+
- Communication/AAC, social-emotional learning, sensory regulation, daily living, cognition, learning, executive function, motor, safety and independence content
- Parent, therapist and owner-admin concepts
- Manual NayaPay subscription workflow:
  - 31-day free period
  - Rs. 799 for 31 days
  - TRX ID submission
  - owner approval/rejection
  - 31-day activation from approval
- Production data model/API starter in `backend/`

## Important
The included frontend demo still uses localStorage for demonstration. The backend starter shows the secure server-side architecture needed before accepting real payments.

Do not advertise MindBloom as a cure for autism. It is a learning/support product intended to complement qualified professional care.
