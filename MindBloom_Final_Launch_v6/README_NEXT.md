# MindBloom — Complete UI Shell

This package contains the polished responsive MindBloom UI plus the full-stack backend starter.

To connect it for production:
- Move the visual shell into Next.js App Router pages/components.
- Connect login/session APIs.
- Connect Prisma models and server-side subscription middleware.
- Replace demo payment modal with `/api/payments`.
- Build the private OWNER dashboard using `/api/owner/payments`.
- Enforce subscription on the server, never in localStorage.
- Add testing, rate limits, monitoring, backups and privacy controls before launch.

MindBloom should be positioned as autism-support learning/development software, not as a cure.
